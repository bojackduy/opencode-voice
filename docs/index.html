Typing prompts. Reading responses. Breaking flow.

Long, detailed prompts are slow to type. Long assistant responses pull your eyes off the code. Generic dictation tools don't know about your editor, your model, or your codebase — and cloud voice tools send audio you'd rather keep local.

opencode-voice lives inside OpenCode. It inserts transcripts at your cursor as editable text (it never auto-sends), and speaks replies aloud with code-aware normalization. Voice becomes a first-class input and output, not a sidecar.

Built for how developers actually work

Install in two minutes

Prerequisites: brew install whisper-cpp sox (macOS) and a Piper binary + voice model.

OpenCode v2 (cli.json)

{
  "plugins": [{
    "package": "@bojackduy/opencode-voice",
    "options": {
      "endpoint": "https://api.anthropic.com/v1",
      "model": "claude-haiku-4-5",
      "apiKeyEnv": "ANTHROPIC_API_KEY"
    }
  }]
}

OpenCode v1 (tui.json)

{
  "plugins": [
    "opencode-voice"
  ]
}

Then run npm i -g @bojackduy/opencode-voice and configure via tui.json plugin options.

Frequently asked

Does it auto-send my transcript?

No. Transcripts are inserted at your cursor as editable text. Nothing is submitted unless you use /stt-submit, enable sttAutoSubmit, or use conversation mode.

Does audio leave my machine?

By default, no. STT runs whisper-cpp locally; TTS runs Piper/Chatterbox/VieNeu locally. The only network calls are to your configured LLM endpoint for text normalization. A hosted STT endpoint is optional.

Which OpenCode versions are supported?

Both v1 and v2, via capability detection (never version-string checks). All 19 commands register on both.

Can it speak Vietnamese?

Yes. VieNeu-TTS handles Vietnamese + English code-switching in a single utterance. Piper and Chatterbox are English-focused. Select the engine with /tts-engine.

Is it free?

Yes, AGPL-3.0. Free to use, modify, and self-host. Support development via GitHub Sponsors.
